## 实现

- AgentSession 持有历史和 IDLE/RUNNING/CLOSED 状态，每轮创建新 AbortController。
- COMPLETE 和 MAX_STEPS 正常返回时保存完整历史；异常、取消与预算错误不提交当前轮。历史回滚不撤销工具副作用。
- ConsoleSession 基于 readline 事件接收输入；按回车提交时忙碌则丢弃，不排队。支持 /reset、/exit、EOF 和两级 Ctrl+C。
- session 命令装配 Ollama、现有 ContextManager、四个只读仓库工具与 Runner；通过 --workspace 指定工作区（默认当前目录），启动时验证真实目录；默认流式，--no-stream 走非流式，每轮最多10次请求。
- 主入口在会话期间移交 SIGINT 所有权；退出等待任务收尾并释放标准输入管道。

## 当前实现补充

- ModelEvent.TEXT_DELTA 用于显示，DONE.result 包含完整文字、工具调用和统计。Ollama 原生参数为服务端解析后的对象，Provider 按块累积完整调用；缺少完成标记不返回成功。
- Runner 将文本转换为 AgentEvent；完整消费并校验响应后发送 MODEL_FINISHED，携带步数和统计。它不代表 Agent 任务结束；工具与任务生命周期事件仍待 #26。
- ConsoleSession 的输出状态在每次 execute 内初始化，忽略空增量。正常结束只补必要换行；取消/失败明确标记已显示输出不完整、整轮未保存；步数耗尽提示历史已保存、任务未完成。
- /multiline 收集空行与缩进，整行 /send 提交、/cancel 或 Ctrl+C 放弃；其他命令作为正文。EOF 放弃未提交草稿；这不等于自动多行粘贴编辑器。
- 已知模型失败样例：目录回答遗漏实际目录项、不能自主定位 session 注册位置。缺少原始工具记录时不能确定全部归因，更不能当作通过。
