## 实现与设计

- ToolDefinition 关联输入 Schema 和 execute；ToolDescription 供模型读取。
- ToolRegistry 拒绝重复名称，包装具体泛型工具为统一 invoke，并列出公开描述。
- ToolExecutor 处理未知工具、超时、取消；invoke 处理参数校验及执行异常。
- 同一份 Zod Schema 推导 AddInput、执行运行时校验并生成 JSON Schema，避免手工维护两份规则。
- Provider 映射工具描述、assistant 调用及 tool 结果；CLI tools-demo 固定两次非流式请求，不实现自动 Agent Loop。
- 单次超时覆盖默认值，两个入口复用校验；非法超时配置拒绝执行。
- 超时、取消结束等待并通知工具，成功后清理定时器和监听器。

## 限制与后续

- 不支持流式工具调用，明确返回 unsupported；支持流式普通文本。
- 只执行一轮工具；再次请求工具时失败退出。后续 Agent Loop 不在 Day 2 实现。
- Promise.race 只结束等待；不能强停忽略取消信号的工具、抢占同步阻塞代码或回滚副作用。
- CLI 对未知普通异常仍显示通用错误，错误展示可以后续改进。
